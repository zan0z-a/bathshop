# Ванная Просто — ASP.NET Core MVC

Простой сайт для ремонта и реставрации ванных комнат. Проект использует ASP.NET Core MVC, Entity Framework Core, SQLite и ASP.NET Core Identity.

## Требования

- .NET 8 SDK
- Подключение к интернету для загрузки фотографий из Unsplash и шрифтов Google Fonts

## Запуск

В терминале перейдите в папку с файлом `BathroomRenovation.csproj` и выполните:

```powershell
dotnet restore
dotnet run
```

При первом запуске автоматически создаётся файл `bathroom.db` и добавляются демонстрационные услуги, проекты, акции, отзывы и учётная запись администратора.

## Вход администратора

- Email: `admin@gmail.com`
- Пароль: `Admin12345`

Данные для администратора задаются в `Data/SeedData.cs`. Для реального сайта обязательно измените пароль и не храните его в исходном коде.

## Роли

- Admin: управление контентом, пользователями, ролями, отзывами и заявками.
- Manager: просмотр отзывов и обработка заявок.
- User: личный кабинет, история заявок и отправка отзывов.

Новые регистрации автоматически получают роль `User`. Оставлять заявки и отзывы могут только авторизованные пользователи. Новые отзывы сразу отображаются на сайте. Администратор может удалять отзывы.

## Разделы

Главная, о компании, услуги, портфолио, акции, отзывы, контакты, заявка на ремонт, личный кабинет и админ-панель.

## Примечания

- Контактные телефон, email и адрес в шаблоне демонстрационные. Замените их в `Views/Shared/_Layout.cshtml` и `Views/Contacts/Index.cshtml`.
- Ссылки на фотографии портфолио можно менять через админ-панель.
- Для сброса учебной базы данных удалите `bathroom.db` и запустите сайт снова. Для рабочего сайта используйте миграции EF Core.
